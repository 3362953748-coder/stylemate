# 用户调研报告

> StyleMate · AI 个人风格写作助手
> 调研时间:2026 年 11 月

---

## ⚠️ 调研性质说明(请先读这一段)

**本报告是案头研究(desktop research),不是一手用户研究。**

必须诚实区分三类内容:

| 标记 | 含义 |
|---|---|
| **【数据】** | 来自公开可查的调研报告、问卷、评测文章,附来源 |
| **【观察】** | 从公开评测与用户自述中归纳的定性观察,非统计结论 |
| **【假设】** | 我基于上述材料做出的**设计假设**,尚未经一手访谈验证 |

> **这意味着**:本报告中的用户画像与场景是**待验证假设**,不是已确认的事实。
> 面试时如果被问到「你怎么做的用户调研」,正确的回答是:
> 「我先做了案头研究定位问题域,识别出三个关键假设 —— 风格感知度不足、风格资产零沉淀、
> 抄袭与个性化之间的取舍无控件 —— 然后用可运行原型做验证性测试。
> 一手访谈是下一步计划。」
>
> 把自己没做过的事说成做过,是在这个岗位上最致命的失误。

## 一、问题域:三个待验证假设

### 假设 H1 · 风格感知度不足

> 用户能感知到「AI 写的不是我」,但说不清差在哪。

**【数据】支撑**

- Brafton 2026 营销人调研中,「内容听起来千篇一律」以 **87 票**成为第一大问题,远超事实错误(51 票)、质检缓慢(46 票)
- 12,847 份问卷调研中,商业文案场景下现有工具在**品牌调性匹配上评分仅 6.2/10**
- 超过 **60%** 的 AI 生成文章存在严重内容雷同(自媒体从业者统计)

**【观察】**

- Eden 的官方文档专门论述了这一点:「把一段帖子粘给 ChatGPT 说『写得像我这样』几乎得不到任何持久的东西。它只模仿单一样本的表层特征,下次就忘了」
- VoiceMoat 的表述更直接:「你的声音不是一个形容词。『口语化』形容了数百万个写作者」
- Fostera 提出了可验证的判断标准:「『语气专业而有感染力』毫无用处;『你用一句话的论断开头,段落不超过两句,偏爱具体名词而非形容词,几乎从不用感叹号』才是能真正用来写的档案」

**【观察】**可拆解为七类可观测特征

| 特征维度 | 观察点 | 示例 |
|---|---|---|
| 句子节奏 | 短促/绵长/碎片/变化 | 「多为 8–18 词,偶尔用一行短句强调」 |
| 词汇 | 日常/专业、常用词、禁用词 | 「用朴素动词;领域术语需首次解释」 |
| 开头 | 结论先行/提问/场景铺陈 | 「以结论开头,不要铺垫段落」 |
| 结构 | 标题/要点/故事/论证顺序 | 「段落短;要点仅在真正可扫读时使用」 |
| 语气 | 温度、确定性、幽默、正式度 | 「扎实友好;干式幽默罕见且简短」 |
| 标点 | 破折号、分号、括号、emoji | 「少用破折号;客户邮件不用 emoji」 |
| 证据 | 例子、数字、引用、资历 | 「来源紧邻论点;不编造精确度」 |

**这直接决定了 StyleMate 的提取设计**:不输出「活泼专业」,而输出上述七类中可观测的具体特征。

### 假设 H2 · 风格资产零沉淀

> 用户每次都要重新描述自己想要的语气,工具不积累任何东西。

**【数据】支撑**

- 87.3% 曾使用 AI 写作工具,**42.1% 为高频使用者(每周 3 次以上)** —— 需求真实且高频
- 某 MCN 机构统计:使用多个 AI 工具时需频繁切换平台,**工具切换损耗占创作时间的 37%**
- 某美妆账号因切换写手导致**完播率下降 41%**(风格一致性的业务价值)
- 某头部知识博主连续 3 天未更新,损失 23% 粉丝

**【观察】**现有工具的共性问题

- Kimi 的常见用法已经逼近 StyleMate 的核心价值(10 条爆款笔记 → 分析共同规律 → 按规律写新的),
  但它是**一次性对话** —— 分析结果无法沉淀,下次要重新贴一遍
- Eden 明确对比了账号连接型工具的局限:那些工具「只从一个来源学习(你已发布的账号内容),
  且进入一个黑盒。如果草稿不对,你只能在聊天里抱怨」
- ChatGPT 的自定义指令与记忆也有局限:「它们是静态偏好,不是学习循环 —— 模型不会研究你的修改并改进,
  长对话中还会被其他上下文稀释」

**【数据】**传统内容库方案的佐证

某自媒体从业者在实践中得出结论并明确建议:

> **建议创建个人的写作模板库了。** 这种方法能够显著地提升写作效率,还能保持内容的独特性。
> 我的模板库包括了各类文章的结构,常用的表达方式以及专业术语的解释等内容。

**这几乎就是 StyleMate 的产品定义**,且来自一线从业者的自发实践,而不是我臆想的需求。

### 假设 H3 · 抄袭与个性化之间无控件

> 用户想要「像我」,但太像又显得在抄自己/抄别人 —— 中间没有可调旋钮。

**【数据】支撑**

- 73.6% 的用户担心生成内容的 AI 痕迹过重,可能导致**平台限流**或学术不端风险
- 超过 **80%** 的 AI 生成文章存在「机器味」过重问题
- 超过 **60%** 的 AI 生成文章存在严重内容雷同
- 使用 AI 完全代替人工创作的账号,**90 天内留存率仅 23%**,远低于行业平均值
- 2024 Q3,超过 **47%** 的 AI 生成内容在审核时被判定为低质量

**【观察】**竞品已验证这个控件的价值

文风盗贼的实际使用记录:

> 风格浓度 —— 100% 浓度太像原作者,容易有抄袭感,调到 60-70% 刚刚好。

这条反馈直接促成了 StyleMate v1.1 的风格强度调节功能。

**【观察】**VoiceMoat 的重要区分

> 移除 AI 的声音,与添加你自己的声音,是两件不同的事。

这条区分很重要 —— 用户要的不是「不像 AI」,而是「像我」。前者靠禁用词清单,后者靠风格档案。

## 二、用户画像(待验证假设)

> 以下画像基于问题域推导,**尚未经一手访谈确认**。

### 画像 A · 多平台自媒体创作者(推测占比 40%)

| 维度 | 描述 |
|---|---|
| 典型身份 | 小红书 + 公众号双平台运营,业余或半职业 |
| 核心痛点 | 一稿多发时每个平台都要重写;AI 味被限流;调性随心情波动 |
| 现有解法 | 手动改 / 找模板 / 让 AI 直接生成再大改 |
| StyleMate 价值 | 一个模板 + 四个场景 = 一次录入,多处复用 |
| 关键功能 | 多版本对比、场景切换、强度调节 |
| 成功信号 | 建模板后每周复用 ≥3 次 |

### 画像 B · 职场内容岗 / 品牌运营(推测占比 25%)

| 维度 | 描述 |
|---|---|
| 典型身份 | 企业市场部,每周 3–5 篇推文/内宣 |
| 核心痛点 | 换写手调性漂移;品牌语气要求严;重复劳动多 |
| 现有解法 | 建品牌语气指南文档,但 AI 不读它 |
| StyleMate 价值 | 用品牌旧文建模板,新人也能产出稳定调性 |
| 关键功能 | 正式邮件场景、模板共享(未来)、一致性检测 |
| 成功信号 | 团队内多人共用同一模板 |

### 画像 C · 独立咨询 / 专业服务者(推测占比 20%)

| 维度 | 描述 |
|---|---|
| 典型身份 | 自由顾问、设计师、律师,写提案与客户邮件 |
| 核心痛点 | 要快但不能显得敷衍;要专业但不能失去个人感 |
| 现有解法 | ChatGPT + 自己反复微调提示词 |
| StyleMate 价值 | 保留自己的表达骨架,只优化结构与措辞 |
| 关键功能 | 强度低档(20–45%)、正式邮件场景、可编辑风格指令 |
| 成功信号 | 明确表示「省了重复描述需求的时间」 |

### 画像 D · 学生 / 求职者(推测占比 15%)

| 维度 | 描述 |
|---|---|
| 典型身份 | 实习申请、求职信、简历自荐 |
| 核心痛点 | 语气要正式但不僵;要有个人感但不能出格 |
| 现有解法 | 网上抄模板 |
| StyleMate 价值 | 用自己写过的申述/邮件建模板 |
| 关键功能 | 正式邮件场景、可编辑风格指令 |
| 成功信号 | 简历投递后反馈率提升 |

## 三、关键场景(待验证假设)

### S1 一稿多平台分发

```
输入:一篇 1200 字干货
现状:小红书、公众号、知乎各改一遍,改到怀疑人生
StyleMate:选「我的小红书风格」+ 小红书场景 → 得到短段落 emoji 版
          同时保留公众号版本(同一原文,不同场景)
关键指标:一次操作产出多平台版本,耗时 < 5 分钟
```

**竞品参照**:某多平台转换工具实测,1200 字文章转三个平台「只需要稍微调整一下例子细节和个别表达」。

### S2 品牌调性一致性

```
输入:品牌过往 10 篇推文
现状:新人写出来不像一个品牌;换写手后数据下滑 41%
StyleMate:建品牌模板 → 全员沿用 → 输出稳定
关键指标:不同写手产出的内容一致性评分 ≥ 80
```

### S3 快速产出且不失真

```
输入:客户提案初稿(自己写的,只是乱)
现状:AI 一改就没个人味了,或完全不敢用
StyleMate:正式邮件场景 + 正式度 4 + 强度 50%
        → 保留原文骨架与用词习惯,只优化结构
关键指标:直接采纳率 ≥ 50%,微调轮次 ≤ 1
```

### S4 说不清自己的风格

```
输入:3 篇自己的旧文
现状:想描述自己的风格但只会说「比较自然」
StyleMate:给出「松弛日常白描体」+ 五维具体特征
        → 用户确认或编辑后保存
关键指标:模板创建率 ≥ 25%
```

## 四、需求优先级(基于上述推导)

| 优先级 | 需求 | 对应假设 | 竞品状态 |
|---|---|---|---|
| **P0** | 从范文提取可观测特征 | H1 | 部分竞品有,但粒度粗 |
| **P0** | 风格档案持久化可编辑 | H2 | 少数有(黑盒或不可编辑) |
| **P0** | 强度/浓度可调 | H3 | 少数有 |

## 五、验证计划(下一步)

**当前状态:假设已形成,一手验证未做。** 计划如下:

### 阶段一 · 可用性测试(1 周,5–8 人)

| 目标 | 方法 | 成功标准 |
|---|---|---|
| 验证 H1:用户能否看懂五维特征 | 让用户读 AI 生成的风格描述并复述 | ≥ 70% 复述准确 |
| 验证提取质量 | 给同一批范文,比较 AI 提取与用户自述 | 用户认为「基本符合」≥ 60% |
| 验证 H2:模板复用动机 | 观察首次使用后一周内是否主动回来 | 复用率 ≥ 60% |
| 验证强度控件直觉性 | 不解释,看用户是否理解滑块含义 | ≥ 70% 正确选择 |

### 阶段二 · 定量问卷(2 周,n ≥ 200)

- 沿用 12,847 份问卷的量表设计,对齐可比性
- 核心量表:AI 味感知度、改写采纳率、工具切换成本、模板复用意愿
- 招募配额按四类画像分层

### 阶段三 · 行为数据(上线后持续)

| 指标 | 定义 | 目标 |
|---|---|---|
| 模板创建率 | 创建 ≥1 个模板的注册用户占比 | ≥ 25% |
| 模板复用率 | 被调用 ≥1 次的模板占比 | ≥ 60% |
| 直接采纳率 | 生成后未修改即保存的比例 | ≥ 50% |
| 次周留存 | 7 日内回访 | ≥ 30% |
| 强度调节使用率 | 用过强度滑杆的比例 | ≥ 30%(验证 H3) |
| 一致性检测使用率 | 用过检测的比例 | ≥ 25%(验证空白需求) |

## 六、调研局限

1. **案头研究,非一手研究** —— 所有数据来自公开二手材料,存在选择偏差
2. **画像占比是推测** —— 四类画像的 40/25/20/15 分布基于问题域推导,无统计基础
3. **场景是推演** —— S1–S4 由调研结论演绎而来,未经真实用户验证
4. **中文垂类工具覆盖不全** —— 部分工具功能矩阵未穷尽核对
5. **无定量验证** —— 尚无自有问卷或访谈数据
6. **无用户研究结论** —— 因此本报告不应被称为「用户调研报告」,更准确的说法是
   「用户调研的案头研究阶段产出 + 验证计划」

> **诚实是这份材料最大的价值**。它告诉面试官:我知道自己知道什么、不知道什么,以及下一步怎么补。
